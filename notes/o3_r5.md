# O3 recentré : infinité pour r = 5 (trois termes) — pistes, aucun résultat

Statut : **réflexion préliminaire, rien de prouvé.**

## Pourquoi la construction de Price s'arrête à r = 6
(X+Y)^r = (X−Y)^r + Σ_{j impair} 2·C(r,j)·X^{r−j}·Y^j a ⌈r/2⌉+1 termes à droite. Pour r = 5 :
(X+Y)^5 = (X−Y)^5 + 10X^4Y + 20X^2Y^3 + 2Y^5, soit 4 termes, alors qu'il en faut 3.

## Tentative : regrouper les termes impairs
(X+Y)^5 − (X−Y)^5 = 2Y·(5X^4 + 10X^2Y^2 + Y^4). Il faudrait écrire la quartique Q = 5X^4 + 10X^2Y^2 + Y^4
comme somme de DEUX formes « puissantes » à coefficients positifs. Les deux complétions de carré donnent
- Q = (Y^2 + 5X^2)^2 − 20X^4,
- Q = 5(X^2 + Y^2)^2 − 4Y^4,
toutes deux avec un signe moins : on obtient des relations à 2 + 2 termes, pas 3 + 1. Raison : 5t^2 + 10t + 1
a deux racines réelles négatives, donc Q n'est pas de la forme α(·)^2 + β(·)^4 avec α, β > 0 sur ces bases.
Impasse pour cette identité précise ; d'autres identités de degré 5 restent à essayer (non fait).

## Ce que disent les données
Recherche exhaustive (search/search_r5.py, sans hypothèse sur les pgcd deux à deux) : voir REPORT.md.
Les deux solutions connues n'ont pas de structure commune évidente :
- 2^5·17^6 + 7^11 + 2^5·3^6·7^8 = 3^7·13^7 (Kitamura), équivalent à 17·34^5 + 7·49^5 + 1029·42^5 = 1521·39^5 ;
- 2^8·3^10·5^7 + 2^12·23^6 + 11^5·13^5 = 3^7·61^5 (Cambie).
Cambie écrit dans le fil qu'il n'ose pas deviner fini ou infini pour r = 5.

## Heuristique
Nombre attendu de solutions de taille ~X : X^{-1/5} par échelle dyadique (dossier, F.2), somme convergente :
un nombre fini est attendu en l'absence de structure algébrique. Les données (2 solutions, les deux < 2·10^12) vont dans ce sens.
C'est une heuristique, pas un argument.
